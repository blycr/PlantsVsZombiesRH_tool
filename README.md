# PVZ 融合版 3.6.1 交互式修改器 v7

游戏内动态开关极速冷却、阳光越花越多、任意种植、植物无敌、僵尸一击必杀、植物状态加速以及游戏整体速率调节。全功能随开随关，模块化架构，权限按需申请（普通用户即可运行）。

---

## 功能说明

| 键 | 功能名称 | 游戏表现 |
| :---: | :--- | :--- |
| `1` | 极速冷却 ×100 | 所有卡牌、锤子、手套 CD 瞬间满格，可无限连种。 |
| `2` | 阳光越花越多 | 无论捡阳光还是种植消耗，阳光值只增不减，越种越多。 |
| `3` | 任意种植与重叠融合 | 水面/屋顶无需睡莲/花盆；兼容植物正常融合；不兼容植物物理重叠于同格各自运作。 |
| `4` | 植物无敌 | 全场植物免疫一切啃食与秒杀，铲除与爆炸自毁仍正常生效。 |
| `5` | 僵尸一击必杀 | 任意伤害均可秒杀僵尸，包括植物弱攻击。 |
| `6` | 特定植物状态加速 | 大嘴花咀嚼时间缩短至约 1/20；土豆地雷准备时间缩短至约 1/20。动画与音效仍正常播放。 |
| `7` | 游戏整体速率调节 | 支持 0.1x（慢动作）至 10.0x（极速）连续调节，输入 1.0 恢复原速。 |

---

## 环境准备

### 1. 安装 uv（推荐的 Python 包管理器）

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

安装后重启终端，验证：

```bash
uv --version
```

### 2. 安装 Python 3.12

```bash
uv python install 3.12
```

## 使用方法

### 第一步：进入游戏关卡

启动 植物大战僵尸融合版 3.6.1，进入任意关卡（冒险模式、挑战模式均可）。

### 第二步：运行修改器（无需管理员）

在脚本所在目录打开 PowerShell（普通用户权限即可），执行：

```bash
.venv\Scripts\python pvz_fusion_cheats_v7.py
```

> 修改器会自动检测进程权限：若普通用户权限无法附加游戏进程，会弹出 UAC 对话框申请管理员权限并在原窗口重新运行，无需手动右键"以管理员身份运行"。
>
> 注意：PlantsVsZombiesRH.exe 本身以普通用户权限启动（直接双击游戏即可），修改器即可在同等权限下附加，无需提权。

### 第三步：菜单控制

```text
=========================================================================================
        PVZ Fusion 3.6.1 修改器 v7 (交互式对齐优化版) - 已附加进程: XXXXX
=========================================================================================
 [1] 极速冷却 ×100           [ 已关闭 ] - 所有卡牌和手套的CD瞬间冷却完毕
 [2] 阳光越花越多            [ 已关闭 ] - 捡阳光或种植消耗阳光时，阳光皆为 100 倍增加
 [3] 任意种植与重叠融合       [ 已关闭 ] - 解除地形限制可水面重叠种植，且保留兼容植物自动融合逻辑
 [4] 植物无敌                [ 已关闭 ] - 植物免疫啃食/秒杀/碾压/落水，且不影响铲除与爆炸自毁
 [5] 僵尸一击必杀            [ 已关闭 ] - 所有僵尸在受到任意伤害时立即死亡
 [6] 特定植物状态加速         [ 已关闭 ] - 大嘴花咀嚼与土豆地雷准备等时间加速 20 倍
 [7] 自由调节游戏整体速率     [ 已关闭 ] - 自由调节游戏整体运行速率 (支持加速/减速，默认 1.0x)
 -----------------------------------------------------------------------------------------
 [A] 一键开启所有功能
 [R] 还原所有修改 (全部重置)
 [Q] 还原并退出修改器
=========================================================================================
请输入选项序号 (例如 1) 并按 Enter:
```

- 输入数字（1~7）切换对应功能的开关状态。
- 输入 A 一键激活全部功能（功能 7 速率调节除外，避免打断输入流程）。
- 输入 R 还原全部内存补丁（功能状态重置为关闭，游戏不受影响）。
- 输入 Q 或 Ctrl+C 还原所有补丁并退出，游戏可安全继续游玩。

## 注意事项与功耗优化

- 修改器零 CPU 开销：等待输入时主线程挂起，CPU 占用恒定 0.0%，不会引起发热。
- 控制重叠植物数量：重叠种植过多时，Unity Spine 骨骼动画与弹幕物理碰撞检测量呈指数级增长，是高功耗的主要来源。建议单格重叠不超过 5~10 棵。
- 锁定帧率：在游戏显卡设置或驱动控制面板中将帧率上限锁定在 60 FPS，可降低 50% 以上的 GPU 功耗。
- 纯内存操作：修改器不读写任何游戏存档或安装文件，关闭后效果完全消失，100% 安全。
- 游戏版本绑定：所有内存偏移均针对 PVZ 融合版 3.6.1 硬编码，其他版本不适用。
