# PVZ 融合版 3.6.1 交互式修改器 v4

游戏内一键开启 **极速冷却**、**阳光越花越多**、**任意种植（无视地形/重叠种植且兼容融合）**、**植物无敌** 以及 **僵尸一击必杀**。支持部分功能的随开随关，具有高度的模块化和扩展性。

---

## 🌟 修改器功能说明

| 功能名称 | 默认热键 | 技术逻辑 | 游戏表现 |
| :--- | :--- | :--- | :--- |
| **极速冷却 ×100** | `1` | 劫持 `CardUI.CDUpdate` 接口，将帧间隔时间 `Time.deltaTime` 放大 100 倍。 | 所有植物卡牌、锤子、手套等道具CD瞬间恢复，无限连种。 |
| **阳光：越花钱越多** | `2` | 拦截 `Board.GetSun` 增加阳光，并将 `Board.UseSun` 扣除改写为放大 100 倍的累加。 | 无论捡起还是种植扣除阳光，阳光值都不减反增，种植越快增加越快。 |
| **任意种植与重叠融合** | `3` | 强制 `CreatePlant.CheckBox` 返回 `true`；NOP 掉 `SetPlant` 的融合跳过；改写不兼容跳转。 | - **地形放行**：陆地植物直接种在水面（无睡莲）或屋顶（无花盆）。<br>- **兼容融合**：豌豆+坚果正常融合花生。<br>- **不兼容重叠**：豌豆+向日葵等物理重叠于同一格子，各自工作。 |
| **植物无敌** | `4` | 拦截 `Plant.TakeDamage` 函数头部并直接执行 `ret` 强行返回。 | 全场植物对任何撕咬或秒杀机制彻底免疫。 |
| **僵尸一击必杀** | `5` | 在 `Zombie.TakeDamage` 函数头部注入代码，强行将第三参数伤害值劫持为 `999999`。 | 全场僵尸受到任何哪怕 1 点微弱伤害也会瞬间倒地死亡。 |

## 🛠️ 环境准备

### 1. 安装 uv

`uv` 是一个极速的 Python 项目包管理器。在 PowerShell 中以管理员权限运行以下命令进行安装：

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

安装完成后，建议**重启终端**，然后验证：

```bash
uv --version
```

### 2. 安装 Python (推荐 3.12)

```bash
uv python install 3.12
```

## 🎮 使用方法

### 第一步：进入游戏关卡
启动游戏 **植物大战僵尸融合版 3.6.1**，并**进入任意关卡**（如冒险模式第一关）。

### 第二步：以管理员身份运行修改器
在 [pvz_fusion_cheats_v4.py](file:///C:/Users/blycr/Desktop/sth/PC_PVZ-Fusion-3.6.1/pvz_fusion_cheats_v4.py) 脚本所在文件夹下打开 PowerShell（以管理员身份），执行：

```bash
.venv\Scripts\python pvz_fusion_cheats_v4.py
```

### 第三步：菜单控制
控制台启动后将显示如下交互菜单：

```text
==================================================
        PVZ Fusion 3.6.1 修改器 v4 (交互式)
==================================================
 [1] 极速冷却 ×100            [ 已关闭 ] - 所有卡牌和手套的CD瞬间冷却完毕
 [2] 阳光越花越多             [ 已关闭 ] - 捡阳光或种植消耗阳光时，阳光皆为 100 倍增加
 [3] 任意种植与重叠融合        [ 已关闭 ] - 解除地形限制可水面重叠种植，且保留兼容植物自动融合逻辑
 [4] 植物无敌                 [ 已关闭 ] - 所有场上植物免疫任何啃食或秒杀伤害
 [5] 僵尸一击必杀             [ 已关闭 ] - 所有僵尸在受到任意伤害时立即死亡
--------------------------------------------------
 [R] 还原所有修改 (全部重置)
 [Q] 还原并退出修改器
==================================================
请输入选项序号 (例如 1) 并按 Enter: 
```

- 输入功能对应的数字（如 `1`）并按 Enter 即可 **动态开启或关闭** 该功能。修改器会自动打补丁或还原内存，无需重启修改器或游戏。
- 退出修改器时（输入 `Q` 或按 `Ctrl+C`），脚本会**自动清理所有内存补丁和洞穴分配**，保证游戏进程稳定性。

## ⚠️ 注意事项与功耗优化

- **修改器零开销**：修改器运行时平均占用 **`0.0%` CPU**，因为在等待用户输入时主线程会被挂起，不会导致电脑发热。
- **防止电源使用量变高**：
  - 重叠种植过多的植物可能会因为弹幕数量瞬间爆炸而大大增加 CPU 的渲染与碰撞检测负担，请尽量将单格重叠数控制在 5~10 棵以内。
  - **建议在游戏设置中开启垂直同步 (VSync)**，或在显卡控制面板中将该游戏的最大帧率限制在 60 FPS，可直接降低 50% 以上的显卡功耗。
- **管理员运行**：因为修改器需要向 `PlantsVsZombiesRH.exe` 进程写入补丁，因此必须以**管理员权限**运行终端。
- 本修改器仅在内存中做临时劫持，**不会改动您的任何物理文件**，关闭即失效。
